
# Personal Portfolio Website

This is my personal **frontend developer portfolio** built to showcase my skills, projects, and services. The website is fully responsive, interactive, and designed with modern UI principles.

## Features

- Clean and modern **hero section** introducing myself  
- **About Me** section with skills and experience  
- **Services** section showcasing what I offer  
- **Projects** section highlighting my frontend work  
- **Contact** section with email and social links  
- **Dark Mode toggle** to switch between light and dark themes  
- **Scroll animations** powered by [AOS](https://michalsnik.github.io/aos/)  
- **Responsive design** for desktop, tablet, and mobile  
- **Footer** with quick navigation links and social connections 


## Tech Stack

- **HTML5**  
- **CSS3**  
- **JavaScript**  
- **AOS Library** for scroll animations  
- **Git & GitHub** for version control
